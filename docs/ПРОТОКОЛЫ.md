# Протоколы и границы реализации

Это описание исходников данного репозитория, а не обещание совместимости с каждым профилем панели. Список соответствует текущей реализации в этом репозитории.

| Вход / транспорт | Реализация | Что ещё проверить у нас |
|---|---|---|
| VLESS TCP/RAW + REALITY + Vision | Есть | Firefox, Happ, Incy, Mihomo, обычный и мостовой вход, панельные счётчики |
| VLESS TCP/RAW + обычный TLS + Vision | Есть | Сертификат, обновление пользователей, поведение при истечении сертификата |
| VLESS WebSocket за TLS-прокси | Есть | Путь, early data, доверенный PROXY v2, исходный IP клиента |
| Shadowsocks TCP/UDP | Есть только `chacha20-ietf-poly1305` | Совместимость конкретного профиля Remnawave и UDP |
| XHTTP/REALITY | Есть HTTP/2 `stream-one`; `auto` без `downloadSettings` | Отдельная проверка клиента и туннеля |
| gRPC/REALITY или h2c за TLS-прокси | Есть `Tun` и `TunMulti` | Путь, авторизация, длинные потоки и учёт трафика |
| VLESS Mux/XUDP | Есть | DNS, UDP/443, отсутствие утечки входного IP на выходе |

Серверная маршрутизация поддерживает домены, IP, GeoIP/GeoSite, порт, сеть, протокол, inbound и пользователя. DNS поддерживает UDP-резолверы, DoT и системный `localhost`. Есть sniffing HTTP, TLS, QUIC и BitTorrent; выходы Freedom, Blackhole, HTTP CONNECT, SOCKS5 и VLESS/RAW.

Текущие ограничения: другие режимы XHTTP, XHTTP с обычным TLS, DoH, балансировщики и другие алгоритмы Shadowsocks требуют отдельной реализации. `NIGHTVPN_ROUTE_CORE` использует гибрид с Go Xray и не является доказательством работы полностью нативного Rust. `NIGHTVPN_SPLICE=1` — экспериментальная оптимизация: проверять фактические вызовы `splice`, CPU, RAM и ошибки при перегрузке.

На мосту обработчик BitTorrent и блокировка IP зависят от корректной передачи адреса клиента. Без проверенного PROXY protocol событие может содержать IP самого моста. Не включать автоматическую блокировку по такому адресу.

Правило наших VLESS/REALITY клиентских профилей и тестов: `fingerprint=firefox`. Примеры с `chrome` не подтверждают совместимость с нашими клиентами.
